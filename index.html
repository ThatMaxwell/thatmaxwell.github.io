Meet Minus.

A free, open-source team of AI agents that work on real computers. In the cloud or on your own machine, with the AI you already pay for.

Visit Minus View the code

A team, not a chatbot.

Create agents, give each one a job, and let them hand work to each other.

Real computers.

Every agent gets its own computer, or uses yours. It clicks, types and switches windows the way you do, and every action is logged.

Your AI, your keys.

Claude, ChatGPT, Gemini, Grok, Ollama, OpenRouter or any OpenAI-compatible API. Minus never charges for AI.

You stay in charge.

Agents ask before anything they can't undo, like sending email or spending money.

Each agent is a small cloud-shaped character with its own color, expression and accessories. A real 3D model drawn flat, so it turns, blinks and reacts like an illustration.
